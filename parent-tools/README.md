# 子育てことば帖

子育て中の親向けの、無料の道具箱です。ログインなし・AIなしで動くので、運営費は0円です。

| 道具 | できること |
|---|---|
| 声かけ言い換え | 場面（朝の支度・歯みがき・癇癪・きょうだいげんかなど10場面）× 年齢で、つい言いがちな言葉と言い換えを表示。保存（この端末だけ）とコピーができる |
| トイトレQ&A | 年齢・8つの段階（始める前〜夜のオムツ・後戻り・道具・親の気持ち）・34の悩みから選ぶと、共感のひとこと・小さなコツ3つ・相談の目安を表示 |
| ことばチェック | 入力した言葉から、急かし・おどし・怖がらせ・比べる・決めつけ・罰・恥ずかしさ・年齢の断定・効果の断定に印を付け、言い換えのヒントを表示 |

入力した文章はブラウザの中だけで使い、どこにも送りません。

## 中身を増やす・直す

すべての文章は [`data.js`](data.js) にあります。

- 言い換え：`PHRASES` に `{ scene, age, ng, ok, why }` を足す
- トイトレ：`TOILET_QA` に悩みを足す（コツは3つ）
- ことばチェック：`CHECK_RULES` に判定を足す

直したら、リポジトリのいちばん上で次を実行して確認します。言い換えやトイトレの答えの文章が、ことばチェックに引っかからないことも確かめます。

```bash
npx vitest run parent-tools
```

## 公開する（Cloudflare Pages・無料）

このフォルダの中身をそのまま置くだけで動きます（ビルド不要）。

1. [Cloudflare](https://dash.cloudflare.com/) にログインし、**Workers & Pages → Create → Pages → Upload assets** を選びます。
2. プロジェクト名（例：`kosodate-kotobacho`）を入れ、このフォルダの `index.html`・`app.js`・`logic.js`・`data.js` の4つをアップロードします（`test` と `README.md` は不要です）。
3. 公開されたURL（`https://kosodate-kotobacho.pages.dev` など）を、配布したいアカウントのプロフィールや投稿に貼ります。

内容を直したときは、同じプロジェクトに4つのファイルをアップロードし直します。

GitHub と連携して自動で公開する場合は、**Connect to Git** でこのリポジトリを選び、Build command を空欄、Build output directory を `parent-tools` にします。
