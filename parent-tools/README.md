# 子育て向けの配布ツール（2つ）

子育て中の親向けの、無料の道具です。ログインなし・AIなしで動くので、運営費は0円です。
声かけ用とトイトレ用は、それぞれ別のアカウントで配れるように、フォルダごと分かれています。

## 声かけことば帖（[`koekake/`](koekake/)）

| タブ | できること |
|---|---|
| 言い換え | 24場面 × 年齢（1〜2歳〜小学生）で、つい言いがちな言葉と言い換え（約150個）。言葉で探す・保存（この端末だけ）・コピー。日替わりの「今日のひとこと」 |
| コツと発達 | 子どもの心と脳のきほん6つ（前頭前野の発達・感情のラベリング・愛着・自律性・ほめ方の研究・気質）と、声かけの7つのコツ。コツごとに「なぜ効く？（発達・脳のしくみ）」つき |
| タイプ | 8つの質問で気質の傾向をチェック（こまやか・じっくり・ぐんぐん・のびのびの4タイプ＋感覚の敏感さ）。タイプ別の関わり方と声かけの例 |
| ことばチェック | 急かし・おどし・怖がらせ・比べる・決めつけ・罰・恥ずかしさ・気持ちの否定・謝罪の強要などに印を付け、言い換えのヒントを表示 |

## トイトレおたすけ帖（[`toitore/`](toitore/)）

| タブ | できること |
|---|---|
| お悩みQ&A | 年齢・8つの段階・34の悩みから選ぶか、言葉で探すと、共感のひとこと・小さなコツ3つ・相談の目安を表示。「始める前」では、はじめどきチェック（8項目）も使える。答えに関係する「なぜ？（からだと心のしくみ）」と、しくみの解説6つ（ぼうこうの発達・始めどき・夜のホルモン・便秘の悪循環・自律性・ストレス） |
| 声かけ | 誘うとき・できたとき・失敗したとき・うんち・夜・外出の言い換え（23個） |
| タイプ | 声かけ帖と同じタイプチェックで、タイプ別のトイトレの進め方を表示 |
| きろく | 「座れた」「できた」「出ちゃった」をボタンで記録し、1週間分を表で表示（この端末だけに保存） |
| チェック | ことばチェック。年齢の断定（「3歳までに」）や効果の断定（「必ず外れる」）、恥ずかしさで動かす言い方に印を付ける |

入力した文章・保存した言葉・記録は、ブラウザの中だけで使い、どこにも送りません。

## 中身を増やす・直す

- 文章はそれぞれのフォルダの `data.js` にあります（声かけ：`PHRASES`・`TIPS`／トイトレ：`TOILET_QA`・`TOILET_PHRASES`・`READINESS`）。
- タイプチェックは `types.js` にあります。トマスとチェスの気質研究などを家庭向けに簡単にしたもので、診断ではありません。
- `check.js`（ことばチェック）・`types.js`（タイプチェック）・`ui.js`（画面部品）・`style.css`（見た目）は、2つのフォルダに同じものを置いています。直すときは両方を同じ内容にしてください（テストで確かめています）。

直したら、リポジトリのいちばん上で次を実行して確認します。言い換えや答えの文章が、ことばチェックに引っかからないことも確かめます。

```bash
npx vitest run parent-tools
```

## 公開する（Cloudflare Pages・無料）

1つのツールにつき1つのプロジェクトを作ります。ビルドは不要です。

1. [Cloudflare](https://dash.cloudflare.com/) にログインし、**Workers & Pages → Create → Pages → Upload assets** を選びます。
2. プロジェクト名（例：`koekake-kotobacho`）を入れ、`koekake` フォルダの中の8つのファイル（`index.html`・`app.js`・`logic.js`・`data.js`・`check.js`・`types.js`・`ui.js`・`style.css`）をアップロードします。
3. トイトレも同じように、別のプロジェクト名（例：`toitore-otasuke`）で `toitore` フォルダの中身をアップロードします。
4. 公開されたURL（`https://〇〇.pages.dev`）を、それぞれのアカウントのプロフィールや投稿に貼ります。

GitHub と連携して自動で公開する場合は、**Connect to Git** でこのリポジトリを選び、Build command を空欄、Build output directory を `parent-tools/koekake`（トイトレは `parent-tools/toitore`）にします。
